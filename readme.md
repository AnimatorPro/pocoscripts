# Pocoscripts

Pocoscript is a C compatible scripting language built into Animator Pro

here are as many pocoscripts as I can find, licenses to their respective authors (whoever they may be, I'm not entirely sure with a lot of them)



## ALLFONTS

creates a specimen book for all installed fonts

## ALLSTAR

By PhilD

creates an animated star field, with parameters. Based on STARFIEL.POC

## APWCOLPR

outputs the current palette as a csv file, one R, G, B triple per row.

## BADBASK

Example program that loads a font from a given path and filename, renders some text and outputs a FLI

## BADBMP 

seems to have been created to debug BMP parsing. 

## BREAKFAS, BREAKHB, BREAK001, BREAKOUT, BREAKSLO

the classic brick smashing game, various versions with slight differences.

## BUG.POC

some kind of crash test

## BULLET

designed to place shadowed 'bullets', either single or double, on presentation charts.  

BULLET.DOC, BULLET.POC, L-BULLET.CEL, M-BULLET.CEL, S-BULLET.CEL and V-BULLET.CEL form the whole package with the doc explaining how it is used in detail.
